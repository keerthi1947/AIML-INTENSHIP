# Task 4 - Logistic Regression Classification

## Objective
Build a binary classifier using Logistic Regression.

## Tools Used
- Python
- Pandas
- Scikit-learn
- Matplotlib

## Dataset
Breast Cancer Wisconsin Dataset

## Steps Performed
1. Loaded the dataset.
2. Split data into training and testing sets.
3. Standardized features using StandardScaler.
4. Trained Logistic Regression model.
5. Evaluated model using:
   - Confusion Matrix
   - Precision
   - Recall
   - ROC-AUC Score
6. Plotted ROC Curve.
7. Performed threshold tuning.

## Results
The model achieved high precision, recall, and ROC-AUC score, demonstrating effective binary classification performance.
